# Perspectives

*The stances. Each page argues one claim about building and running an agentic business.*

---

[Concepts](/concepts) defines terms neutrally and [Principles](/principles) distill what mentors have proven. Perspectives take a position. A perspective is a full argument with a claim, the reasoning behind it, and what it costs you to disagree.

## How the section is shaped

- **One claim per page.** The title is the claim, written as a plain declarative sentence. "Representation Is a Context Problem" is a perspective title. "Compounding Customer Intelligence" is a concept title.
- **The argument is the body.** Named H2 sections, each carrying one move in the argument. Concrete examples over categories.
- **Concepts are linked, never redefined.** If a term has a page in the lexicon, link it and keep going.

## How to use it

- **When you are deciding.** Read the perspective that names the fork you are standing at.
- **When you disagree.** The page should tell you what it would cost to build the other way. If it does not, it is not finished.
